## 1. 目的・原則【確定】

小学校低学年向け、1けた同士の掛け算を学ぶ独立Webアプリ「かけざんマスター」を作る。iPhone・iPad Safariのタッチ操作を最優先する。

- 歴史マスターの学習履歴、未習得・苦手優先、復習、進捗、コイン、ぬいぐるみキャッチャー、わくわくランナー、保護者テスト、バックアップを可能な限り引き継ぐ。
- 参照元の歴史マスターのリポジトリ・データ・公開URLを変更しない。新アプリのバージョン、リポジトリ、公開URL、保存データを独立させる。
- ランナーの iframe 構成、物理挙動、抽選確率、コイン消費、キャラクター、ステージ、途中保存と再開は明示承認なく変更しない。
- 不必要な新機能、外部サービス、サーバー、追加有料サービス、大規模な共通化・リファクタリングは行わない。
- 初期版にはPWA・独自オフライン対応・端末間クラウド自動同期・独自音声読み上げを加えない。データ移行は手動バックアップ／復元を使う。

## 2. 問題と回答【確定】

| 項目 | 要件 |
|---|---|
| 対象 | 1×1〜9×9を、左右の順番を区別する81問。3×4と4×3は別ID・別習得履歴。 |
| 段 | 「3の段」は3×1〜3×9の9問。1〜9の段はすべて最初から自由に学べる。 |
| 問題データ | 問題文と正解はプログラムで自動生成。児童と保護者のいずれも計算式・正解を追加・編集・削除しない。 |
| 問題文の表示 | 児童・テスト両モードの学習画面は「3 × 4」形式で、= と ? を付けない。問題文領域で中央寄せし、大きく1行で表示する。狭幅・縦横でも入力欄・テンキー・ボタンに重ねず、必要なら縦スクロールする。内部データ・問題ID・採点・結果の正答式は維持する。 |
| 解答方法 | 4択は使わない。アプリ画面内の専用テンキーで数字を入力。 |
| 入力制約 | 最大2桁。先頭0不可。末尾から1桁ずつ削除可能。0を含む2桁（10等）は入力可能。 |
| 採点 | 空欄では「こたえあわせ」不可。ボタンを押すまで採点しない。積との数値比較で正誤判定。 |
| 誤答 | 不正解を記録し、正しい計算式を大きく表示。その場で再挑戦せず、復習対象として残す。 |
| 遷移 | 採点後は「つぎへ」で進む。自動遷移・問題スキップなし。 |
| 中断再開 | 同じ出題と採点済み結果を復元。採点前の入力途中の数字は空欄で再開。 |

【設計推奨】安定したID例：問題 `MULT-T03-04`、段 `T01`〜`T09`。全81問の難易度は「基礎」。入力候補1〜99のうち、九九の正解ではない数字も通常の誤答として扱う。タップ領域は原則44px以上とし、数字、削除、こたえあわせ、つぎへを読みやすく配置する。

## 3. 学習モード・抽選【確定】

| モード | 内容 | 抽選 |
|---|---|---|
| 段別学習（1〜9の段） | 左側固定の9問を繰り返し学べる。回答数による強制終了なし。 | 既存 `pickQuestion` を踏襲。回答実績の重み×未習得10／習得済み1。原則直近3問を避ける。 |
| 全段ミックス | 81問から10問セット。同じセットで同一問題は重複させない。 | 既存ジャンル別学習の `sampleStudyEntries` を転用。回答実績による重み付きランダム。未習得10倍を掛けず、段を均等配分しない。 |
| 苦手克服 | 過去に誤答し、現在未習得の問題から最大10問セット。 | 既存 `studyCandidates("weak")` とセット抽選を継承。 |

- 段別・全段ミックス・苦手克服は、同じ81問の通算回答履歴・習得状況・コイン受領状態を共有する。
- 2回連続正解で習得。間違えると連続正解0、習得状態を解除。習得済みの問題も段別で低頻度の復習対象に残す。
- 既存の理解度計算を維持：「（習得済み＋1回連続正解×0.5）÷対象問題数」。9段レーダーチャート＋総合理解度を表示。
- 既存の正答実績による抽選重みを継承：未回答5。回答歴ありでは `1 + 4 × [1 − (正解数+1)/(回答数+2)]`。これは表示用の通算正答率とは異なる。
- 学習ホームは段別学習と理解度が中心。ジャンル別学習メニューを「全段ミックス」に置き換え、苦手克服とゲームへの入口も維持する。

## 4. 通算正答率・保護者機能【確定】

- 各81問の通算回答数、通算正解数、正答率（正解数÷回答数）および回答ごとの○×履歴を保存・確認できる。
- 正答率一覧は保護者管理画面に置き、段ごとに閲覧でき、正答率順でも並べ替えられる。未回答は「—（0回）」とする。
- 管理画面は「動作確認」「九九81問の通算正答率」「回答履歴を見る」「その他の既存管理項目」の順。通算正答率は初回表示で閉じ、見出しのタップ・キーボード操作で開閉する。ユーザーの開閉状態を再描画で変更せず、開閉では学習データを書き換えない。
- **直近20回のみの正答率集計は撤回済み。** 20回で打ち切らず、歴史マスター同様の通算実績と回答イベントを採用。
- 保護者用テスト（test）と児童用（student）の学習履歴・カード・コイン・ゲーム記録は混ぜない。保護者画面へのアクセス方式は参照元と同じで、独自PINは追加しない。
- 保護者画面にはテストモード、履歴確認、バックアップ・復元、必要な管理操作を残す。ただし、固定81問の追加・削除・計算式や正解の編集を許さない。歴史教材特有のインポートや更新機能をそのまま公開しない。

## 5. 達成カード・報酬【確定】

- 1〜9の段に**それぞれ異なるキャラクターイラスト**の段別達成カード（計9枚）。当該段の9問が同時点ですべて習得済みになったとき獲得。
- 81問が**同一時点ですべて習得済み**のとき「九九完全制覇カード」1枚を獲得する。過去に段別カード9枚を獲得しただけでは条件を満たさない。
- **計10枚**のカードは、それぞれ異なるキャラクターとしつつ世界観を統一。獲得後に誤答してもカードの所有は取り消さない。
- 完全制覇カードに追加コインは付けない。
- 全81問の難易度は基礎。v0.4.3以降の回答は左側の段による固定報酬：1・2の段1枚、3〜5の段3枚、6・7の段4枚、8・9の段5枚。初正解・初習得・復習・誤答後の再習得も正解1回につき同額を1回だけ付与。不正解とカード獲得の追加コインは0枚。段別・ミックス・苦手克服、student/testに適用（プロフィール別保存）。
- ホームの9段カードに既存金貨画像（17px）と枚数を補足表示し、「正解でコイン3枚」等のアクセシブル名を用意。進捗・理解度・称号・カード全体のタップ領域を維持。ミックス・苦手克服には固定枚数を表示しない。
- 過去の残高・coinEvents・reviewEvents・coinClaimsは保持し、旧未受領報酬を遡及しない。DB／バックアップ12・17ストアを維持し、旧報酬と新報酬を区別して検証・復元する。
- ぬいぐるみキャッチャー通常100コイン、わくわくランナー通常30コイン。保護者用テストは無料。ゲーム途中のセーブ／再開、獲得景品、秘密キャラクター等は維持。

【確定・PR #5マージ済み】ユーザー制作・承認済みのWebP画像10枚を正本として使用。T01〜T09は順にうさぎ・くま・リス・ペンギン・パンダ・コアラ・キツネ・ひつじ・鹿、ALL81は王冠をかぶった猫。全画像1086×1448px（3:4）。獲得済みの一覧・詳細・通知で画像全体を表示し、画像内文字にアプリの文字を重ねない。読み込み失敗時もカード名を表示する。学習用画面では未獲得の表面画像をDOM・CSS・事前読み込みで取得しない。保護者用プレビューのみ全10枚を閲覧でき、獲得記録は変更しない。画像外のカード名・段・獲得状態でアクセシビリティを保つ。Safari実機表示は別途検証待ち。

## 6. 独立保存・バックアップ【確定】

- 新アプリは固有のIndexedDB名を使い、歴史マスターの `history-master-sample-v1` に接続しない。同一GitHub Pagesのオリジンでも相互に学習履歴・コイン・景品・ランナー記録が混在しないこと。
- バックアップの識別子、ファイル名、アプリ識別子、問題ID、段ID、カードID、移行フラグ等も独立させる。
- 手動で書き出し→内容検証→ユーザー確認後に既存データと**置換**して復元する方式を継承。歴史マスターのバックアップは読み込ませない。履歴を自動マージしない。
- 参照元の古い歴史マスターバックアップ（v1〜v10）を新アプリの互換形式として取り込む処理は継承しない。
- 新アプリ固有のDB・バックアップ版を管理し、更新時に新アプリの既存データが消えないようにする。学習履歴・ゲーム保存は公開リポジトリへ入れない。

【設計推奨】DB名 `kakezan-master-v1`、バックアップ識別子 `kakezan-master-backup`、履歴ルーティング識別子 `kakezan-master`。これらの具体値はPR-1の設計レビューで固定し、後から無断変更しない。

## 7. 実装上の重要差分【検証待ち】

1. **選択肢→数値入力**：参照元の `renderQuestion`、`isCorrect`、`grade`、`sessions`、`answers`、`studySets`、`validateStudySets`、`validateBackup` は選択肢番号やシャッフル順に依存する。表示だけでなく保存・採点・復元・二重回答防止をそろえる。
2. **新しい全段ミックス**：参照元のジャンル別モードはタグで絞る。81問全体を対象にし、セットの重複なし・最大10問・再開可能を保つ。
3. **9段＋全制覇カード**：レーダー軸は9、カードは10。歴史マスターの `CARD_MIN_QUESTIONS=50`、10時代用のカード表示・授与・バックアップ検証を変更する。全制覇カードの判定は現在の81問の習得状態による。
4. **保護者機能**：固定81問に対する編集・インポートUI等の扱いを整理しつつ、確認・テスト・復元・学習履歴機能を壊さない。
5. **iframeランナー**：親画面によるコイン決済・保存と子iframeのゲーム通信を保ち、ゲームの計算ロジックや物理を勝手に変更しない。
6. **アプリ分離**：歴史マスターを使っているブラウザのデータに新アプリが触れないことを、同一オリジン条件で確かめる。
7. **アクセシビリティ**：iPhone/iPad Safari、縦横、iPad Split View、アドレスバー伸縮、VoiceOver、文字拡大、タッチ操作と画面切れを確認する。
