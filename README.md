# かけざんマスター

小学校低学年向けの、九九（1×1〜9×9）を楽しく練習する日本語Webアプリです。iPhone・iPadのSafariで使うことを想定し、既存の「歴史マスター」の学習・報酬・ミニゲームの仕組みをできるだけ活用します。

> **今回の基準main** は `762a0ef092b6b97526df681d742b61fb61d69803` の v0.4.7（PR #13マージ済み）です。
>
> **候補 v0.4.8** では、20問テストで100点未満の結果の重複文言を整理し、間違えた問題すべてを出題順に表示します。正しい答えは太字で強調し、100点のお祝い・旧10問セット・苦手克服・保存形式は維持します。詳しくは[検証報告](docs/ISSUE15_REPORT.md)を参照してください。

## 特長

- ホームからすぐ開ける、式とよみかた付きの九九ひょう
- 1の段〜9の段、左側の数を固定した段別学習と20問・100点満点のかけざんテスト
- 全81問の自動生成、画面内テンキーによる数値回答と採点
- 苦手優先の出題、2回連続正解での習得、習得済み問題の復習
- 9段の進捗レーダーと総合理解度、81問別の通算正答率を保護者画面に表示
- 段別9枚＋九九完全制覇1枚、合計10枚の達成カード
- 段別の正解報酬（1〜9の段：1/1/3/3/3/4/4/5/5枚）、ぬいぐるみキャッチャー、わくわくランナー
- 保護者用テストモード、保存・再開、手動バックアップ・復元
- 歴史マスターから完全に分離した保存データ

## 開発・テストの現状

移植基準は `4132cf78e29d2f33c4587b16b58e48f7ef3e17d9`（v1.7.56）。DB `kakezan-master-v1`（schema 12・17ストア）、バックアップ `kakezan-master-backup`（version 12）。新アプリの旧v10/v11バックアップは検証後に復元できます。歴史版の形式、v1〜9、未来版は拒否します。旧問題の履歴・コイン・ゲームは保持し、九九とは別IDで扱います。旧学習セッションは保存のみ継続し、九九として再開しません。v0.1.0/v0.2.0への直接ダウングレードはDB版のためできません。

新しい20問セットを含むバックアップはv0.4.5以前の検証で拒否されるため、復元にはv0.4.6以降を使ってください。旧10問セットや過去の履歴・進捗・コインを自動変換・削除しません。

ローカル起動：`python3 -m http.server 8000` を実行し `http://localhost:8000/` を開きます。外部サービス不要。自動テストはPython 3.12、Node.js、Playwright、Chromiumを使用します。

```sh
python3 -m pip install -r requirements-dev.txt
python3 -m playwright install chromium
PYTHONPATH=tests python3 -m unittest -v progress_cards_test locked_card_test multiplication_test positive_coin_reward_test table_coin_reward_test app_isolation_test app_version_test runner_session_test runner_storage_test runner_integration_test runner_bear_test home_arcade_test
python3 scripts/check_static.py
```

システムChromiumの指定には `KAKEZAN_MASTER_BROWSER` を使用できます。ブラウザ試験は一時コンテキストと架空データのみ使用します。生成画像は `/tmp/kakezan-review` 等に保存し、公開GitHubへ実利用データを入れません。

コピー・変更・除外一覧は [移植マニフェスト](docs/PR1_FILES.md)、検証結果・Safari残件は [PR-1報告](docs/PR1_REPORT.md)、旧形式テストの変更理由は [テスト移植記録](docs/PR1_TEST_ADAPTATIONS.md) を参照してください。本作業ではPages公開・公開設定変更・マージは行っていません。

PR-2の保存互換方針・検証結果・後続作業は [PR-2報告](docs/PR2_REPORT.md) を参照してください。

PR-3の計算方法・カード条件・互換性・テスト結果は [PR-3報告](docs/PR3_REPORT.md) を参照してください。旧歴史カード20件＋九九カード20件（両プロフィール）を保存・復元できます。回答履歴の切り捨て・旧データの自動変換は行いません。Safari実機とクレーン位置計測の残件はPR-4へ引き継ぎます。


## 正式カード画像（main実装済み）

`assets/cards/T01.webp`〜`T09.webp`は順に、うさぎ・くま・リス・ペンギン・パンダ・コアラ・キツネ・ひつじ・鹿。`ALL81.webp`は王冠をかぶった猫です。全10枚WebP、1086×1448px（3:4）、合計4,028,866 bytes。提供ZIPの画像を加工せず、そのまま使用しています。旧E01〜E10の素材も保持しています。

画像全体を表示し、画像内の文字へアプリの文字を重ねません。画像が読み込めなくてもカード名を表示します。画像は装飾として扱い、外側のカード名・段・獲得状態で意味を伝えます。獲得済みカードの詳細はキーボードとタッチに対応します。プレビューは記録を変更せず、管理画面を離れるとプレビュー画像DOMを除去します。

画像の照合・表示・通信・10画面サイズのテスト、回帰結果、Safari実機未確認項目、PR-1からのクレーン透明度・位置計測残件は [PR-5報告](docs/PR5_REPORT.md) に記載します。Chromiumの自動試験は実機Safari確認を意味しません。

過去のPR報告書にある「未公開」「仮画像」「制作待ち」は各工程時点の記録です。現在のmainの実装状況と、実機・配信版の確認状況は分けて扱います。

## 九九ひょう（v0.4.5候補）

ホーム上部・理解度レーダーの前の「🌸 九九ひょうをみる」で開き、「とじる」またはEscapeで閉じます。閉じると元のボタンへフォーカスを戻します。閲覧では学習履歴・コイン・進捗・ゲーム状態を変更しません。

提供WebPを `assets/kuku/kuku-chart.webp`（2172×2896px、887,068 bytes）に無加工で配置。標準HTMLのdialogとobject-fit:containで画像全体を表示し、Safe Area・可変画面高に配慮します。画面外に切り取ったり、閉じるボタンを画像に重ねたりしません。VoiceOver等では段ごとの見出しに続いて全81問の式・よみかたをたどれます。

iPhone、特に横画面は全体表示だと文字が小さくなります。ブラウザ標準のピンチ拡大を制限する設定は追加していませんが、Safari実機での可読性・拡大・閉じる操作は未確認です。専用の拡大UIは今回追加していません。素材検証・必要最小限の試験結果・iPad縦画面の画像は[検証報告](docs/KUKU_CHART_REPORT.md)を参照してください。

今回の局所試験：`PYTHONPATH=tests python3 -m unittest -v kuku_chart_test`。既存の必須GitHub Actionsは維持し、App isolationへこの試験を追加しています。
